# Sistema Bancário Avançado em Python

Projeto desenvolvido com foco na aplicação de conceitos avançados de programação em Python, incluindo Programação Orientada a Objetos (POO), arquitetura modular, decoradores para registro de logs, geradores para eficiência de memória e iteradores customizados.

---
>
> Quando falamos em construir aplicações escaláveis e profissionais, aplicar apenas a lógica básica não é suficiente. É preciso pensar em eficiência de memória, rastreabilidade e manutenibilidade do código.
>
> Recentemente finalizei a evolução do projeto de **Sistema Bancário em Python**, aplicando conceitos avançados de engenharia de software:
>
> 🔹 **Decoradores de Log (`@log_transacao`):** Interceptação de funções de transação para auditoria automática de data/hora e tipo de operação sem alterar o código principal.  
> 🔹 **Geradores (`yield`):** Filtragem e geração de relatórios de extrato sob demanda, otimizando drasticamente o consumo de memória RAM.  
> 🔹 **Iterador Personalizado (`ContaIterador`):** Encapsulamento da navegação da lista de contas ativas utilizando os métodos `__iter__` e `__next__`.  
>
> O resultado é um código modular, limpo e pronto para integração com APIs e banco de dados.
